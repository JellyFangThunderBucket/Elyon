What was recovered

          

            60 recorded edits across 24 file basenames: an authenticated
            evidence broker, append-only journal, provenance graph, browser
            harness, and tests. The original implementation had a command-line
            interface.
          

          
What you can use now

          

            This workbench runs real browser captures, filters observations,
            opens local archives, and exports redacted evidence. Chii adds an
            opt-in live page inspector.
          

          
What still needs device work

          

            Native iOS integration, Safari / WebKit validation, secure remote
            pairing, and a unified Chii-to-broker adapter. No native capability
            is claimed from desktop tests.
