Try it on your phone

  1. Open Console. Drag its ELYON handle or its launcher; drag ↕ to resize.
  2. Use Settings for the existing 20 themes and capture preferences.
  3. In JS mode run document.title. In Await mode run await Promise.resolve(42).
  4. Minimize the panel to use these request fixtures, then open Network.
  5. Check Info for observed capabilities. An installed page console does not grant privileged Safari or Gecko access.

This console shares the page’s thread. It cannot remain responsive if you block that thread with an infinite loop. Exports redact console messages and URLs; DOM and storage values stay local unless you explicitly copy them.
